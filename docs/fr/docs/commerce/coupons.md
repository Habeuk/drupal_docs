# Création de coupons dans Drupal Commerce

Les coupons sont un excellent moyen de promouvoir vos produits et d'inciter les clients à acheter. Avec Drupal Commerce, vous pouvez créer des coupons de réduction pour offrir des remises sur les commandes. Ce guide vous explique comment configurer et gérer des coupons dans votre boutique en ligne.

### Pre-requis

Vous devez creer une promotion, par exemple "Livraison traduite à partir de 100€", pour pouvoir ajouter des coupons.  
Coché la case `Bons de réduction`:
![Ajouter une promotion avec coupon](/assets/add-promotion-select-coupon.png)

### Ajouter les coupons de reduction

Cliquez `Bons de réduction` dans l'onglet :
![Ajouter un coupon](/assets/add-coupon.png)
Ensuite vous pouvez ajouter un coupon en cliquant sur `Ajouter un coupon` ou en `Generer des coupons` pour en creer plusieurs en une seule fois.
