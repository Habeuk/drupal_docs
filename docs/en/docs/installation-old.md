# Installation on an Existing Environment

You have an existing site and want to install our theme. Follow these steps:

- **Installation of Modules**: Retrieve the modules from the `old-installation/modules` folder and copy them into the `modules` folder of your site.
- **Installation of Themes**: Retrieve the themes from the `old-installation/themes` folder and copy them into the `themes` folder of your site.

Next, install the modules you just copied by visiting the `admin/modules` page of your site. Also, install the theme `habeuk_theme` by visiting the `admin/appearance` page. Set this theme as the default theme.

The `habeuk_theme` is now installed on your site. You should follow the rest of the documentation to learn how to add products, pages, and other elements to your site.
