# Theme Configuration

The **E-commerce Sale of Bags (ESB)** theme is a Drupal theme offering advanced configuration options to customize the appearance of your site. This theme provides **10 regions**, enabling the creation of complex layouts. You can configure colors, fonts, text sizes, layout options, and much more by following the advanced configuration guide.  
To access the theme configuration options, go to `admin/appearance/settings/habeuk_theme`.  
_This theme inherits its configuration from the [Wb Universe](https://www.drupal.org/project/wb_universe) theme._

### Adding Google Analytics and Facebook API Keys

1. Create a **Google Analytics** and **Facebook API** account to obtain access keys.
2. Add these keys in the designated fields in the administration interface.  
   ![Google Analytics and Facebook API](/assets/google-analytique-key--facebook-api.png)

### Configuration Group: **Page Templates**

This group allows you to configure page options, including container sizes for different pages. It is divided into **4 subgroups**, each containing page links and a **"Select container"** field.  
The **"Select container"** field offers 4 size options:

- **Container**: Medium display (approximately 1200px).
- **Container-fluid**: Wide display.
- **Width-tablette**: Medium display optimized for tablets (ideal for content pages).
- **Width-phone**: Medium display optimized for mobile devices.

![Wb Universe Page Templates Settings](/assets/settings-wb-universe-page-templates.png)

### Configuration Group: **Layout**

This group allows you to configure the display of side columns (left or right) on your pages. You can also define column sizes using **Bootstrap** classes or custom **CSS** classes (you must create the styles associated with these classes).  
![Wb Universe Layout Settings](/assets/wb-universe-settings-mise-en-page.png)

### Configuration Group: **Forms**

This group allows you to add **CSS** classes to your forms. For example, you can add the Bootstrap class **`mb-4`** to apply a bottom margin.  
![Wb Universe Form Settings](/assets/wb-universe-settings-formulaire.png)

### Configuration Group: **Menu Display**

This group allows you to configure menu display. You can choose between a **horizontal** (default) or **vertical** display.  
For a vertical display, add the **`flex-column`** or **`navbar-nav`** class in the **"Class menu"** field.  
![Wb Universe Menu Display Settings](/assets/wb-universe-settings-menu-display.png)

### Configuration Group: **Region CSS Classes**

This group allows you to add custom **CSS** classes to each of your regions.  
![Wb Universe Region Settings](/assets/wb-universe-settings-region.png)

### Configuration Group: **Table Configuration**

This group allows you to add **CSS** classes to tables.

- For the **"Custom class for tag table"** field, you can add the classes **`mb-4 table table-striped`**.
- For the **"Custom class for container"** field, you can add the classes **`border border-radius-10 px-5 py-4 mb-4`**.

### Conclusion

The **E-commerce Sale of Bags (ESB)** theme offers great flexibility to customize the appearance and structure of your site. You can adjust colors, font sizes, and many other settings by exploring the available options. For additional customizations, consult the theme's advanced settings.
