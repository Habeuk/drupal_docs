# Theme configuration

The **E-commerce Sale of Bags (ESB)** theme is a Drupal theme with advanced configuration options for customising the look and feel of your site. The theme features **10 regions**, allowing the creation of complex layouts. You can configure colours, fonts, text sizes, layout options and much more by following the advanced configuration guide.  
To access the theme configuration options, go to `admin/appearance/settings/habeuk_theme`.  
This theme inherits the configuration of the [Wb Universe] theme (https://www.drupal.org/project/wb_universe).

### Add Google Analytics and Facebook API keys

1. Create a **Google Analytics** and **Facebook API** account to obtain the access keys.
2. Add these keys in the fields provided in the administration interface.  
   [Google Analytics and Facebook API](/assets/google-analytics-key--facebook-api.png)


### Group configuration : **Pages Templates

This group is used to configure page options, in particular the size of containers for different pages. It is divided into **4 sub-groups**, each containing page links and a **"Select container ’** field.  
The **"Select container ’** field offers 4 size options:

- Container**: Medium display (approx. 1200px).
- Container-fluid**: Wide display.
- Width-tablet**: Medium display optimised for tablets (ideal for content pages).
- Width-phone**: Medium display optimised for mobile phones.

![Wb Universe page template settings](/assets/settings-wb-universe-page-templates.png)

### Group configuration : **Page Setup

This group is used to configure the display of side columns (left or right) on your pages. You can also define the size of the columns using **Bootstrap** classes or custom **CSS** classes (you must create the styles associated with these classes).  
[Wb Universe layout settings](/assets/wb-universe-settings-mise-en-page.png)

### Group configuration : **Form** group

This group allows you to add **CSS** classes to your forms. For example, you can add the Bootstrap **`mb-4`** class to apply a margin at the bottom.  
[Wb Universe form settings](/assets/wb-universe-settings-formular.png)

### Group configuration : **Display Menu**

This group is used to configure the menu display. You can choose between a **horizontal** (default) or **vertical** display.  
For a vertical display, add the **`flex-column`** or **`navbar-nav`** class to the **"Class menu ’** field.  
[Wb Universe menu display settings](/assets/wb-universe-settings-menu-display.png)

### Group configuration : **Region CSS Class

This group allows you to add custom **CSS** classes to each of your regions.  
[Wb Universe region settings](/assets/wb-universe-settings-region.png)

### Group configuration : **Config Tables

This group is used to add **CSS** classes to tables.

- For the **"Custom class for tag table ’** field, you can add the **`mb-4 table table-striped`** classes.
- For the **"Custom class for container ’** field, you can add the **`border border-radius-10 px-5 py-4 mb-4`** classes.

### Conclusion

The **E-commerce Sale of Bags (ESB)** theme offers great flexibility for customising the look and structure of your site. You can adjust colours, font sizes and many other parameters by exploring the available options. For further customisation, check out the theme's advanced settings.
