# Advanced theme configuration

Advanced configuration allows you to customise various aspects of the theme, such as font size, title size, colours and many other options.

To access advanced theme configuration, navigate to `/admin/structure/config_theme_entity`. This page displays the list of themes generated by the `config_theme_entity` module. Click on ‘Modify’ to access the theme configuration parameters.

**Notes:**

- Leave the **"Force regeneration of npm files ’** field unchecked, unless you want to regenerate the files for your sub-theme.
- Only tick the **"Generate style files ’** field if you have installed the Node.js and npm modules.

On the configuration page, you can:

- Change the colour of links or buttons**!  
  [Link and button colour](/assets/colour-links-buttons.png)
- Change the basic colours**!  
  [Basic colours](/assets/colour-base2.png)
- Change font size** !  
  [Font size](/assets/font-size.png)

Once you have made your changes, save them. Styles will be regenerated automatically if you have ticked the box **"Generate style files? ’** and the Node.js and npm modules are installed.

For more information see [the documentation for the config_theme_entity module](https://habeuk.com/fr/node/172).
