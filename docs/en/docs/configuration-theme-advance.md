# Advanced Theme Configuration

Advanced configuration allows you to customize various aspects of the theme, such as font size, heading sizes, colors, and many other options.

To access the advanced theme configuration, navigate to `/admin/structure/config_theme_entity`. This page displays the list of themes generated by the `config_theme_entity` module. Click "Edit" to access the theme configuration settings.

**Notes:**

- Leave the **"Force npm file regeneration"** field unchecked unless you want to regenerate your sub-theme files.
- Check the **"Generate style files?"** field only if you have installed the Node.js and npm modules.

On the configuration page, you can:

- **Modify link or button colors**  
  ![Link and button colors](/assets/couleur-liens-boutons.png)
- **Modify base colors**  
  ![Base colors](/assets/couleurs-base2.png)
- **Modify font size**  
  ![Font size](/assets/taille-police.png)

After making your changes, save them. The styles will be regenerated automatically if you checked the **"Generate style files?"** box and the Node.js and npm modules are installed.

For more information, see the [config_theme_entity module documentation](https://habeuk.com/fr/node/172).
