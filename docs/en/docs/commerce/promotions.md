# Configuring Promotions in Drupal Commerce

Promotions are an excellent way to attract new customers and retain existing ones. With Drupal Commerce, you can configure discounts, gifts, or free shipping to boost your sales. This guide explains how to set up these promotional mechanisms.

## ⚙️ Configuring Promotions

### 1. Access the Promotions Interface

- Navigate to the back office: `Administration > Commerce > Promotions`.
- Click on **Add Promotion**.
  ![Add a promotion](/assets/add-promotion.png)

### 2. Create a New Promotion

- **Name**: Give a clear title (e.g., "Summer 2025 Discount").
- **Status**: Activate the promotion.
- **Offer Type**: Select the type of promotion:
  - _Discount_: Percentage or fixed amount.
  - _Gift_: Offer a specific product.
  - _Shipping_: Exempt from shipping fees.
  - ...

![Offer type](/assets/promotion-type.png)

### 3. Define Application Conditions

- In the **Conditions** tab, add rules to trigger the promotion:
  - **Minimum Cart Amount** (e.g., €50).
  - **Product Category** (e.g., apply to sports items).
  - **Customer Segment** (e.g., registered users).
  - ...

![Conditions](/assets/promotion-conditions.png)

### 4. Configure Dates and Limits

- **Validity Period**: Define a start/end date.
- **Usage Limits**:
  - Maximum number of uses per customer.
  - Unique promo code (optional).

![Dates and limits](/assets/promotion-dates-limits.png)

## 💡 Best Practices

- **Test Promotions**: Verify with test orders before launching.
- **Combination of Promotions**: Control whether promotions are combinable.
- **Analyze Impact**: Use reporting tools to measure effectiveness.
